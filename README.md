# Job Genie

I would like you to create an app that allows me to upload or drop a PDF in it and it accurately identifies and extracts NAME, ADDRESS,  Phone number, Job Number,  SUMMARY OF WORKS, DESCRIPTION,  SOR CODES,  QTY,  COST,. These are added to a dynamic spreadsheet-style database that provides columns for all of these variables plus a column for Additional works(variations to the list of works).. A  feature(driven by AI) that turns a description into a clear list of works should be included With the ability to delete, edit or add to the list. The Ai will also match SOR 7.2 v2 codes with each of the list of works. These codes will be drawn from a pdf SOR 7.2 BOOK in the main file of the application to ensure accuracy and restriction to find anything else but the actual SOR codes. The additional works column will also have this feature to enable me to past a description of extra works into the section and it will convert it into a clean list of works matched to the relevant SOR CODES.. The Spreadsheet-style Database will also enable each job to be assigned to a team, a feature button when clicked it displays all of the Allsaints Teams, you just need to click a team and that team is assigned that job, the teams name will now be displayed in that jobs column plus simultaneously sent to the specific WhatsApp group. A progress bar should be integrated into the job column, when clicked it opens a facility to type the progress of the job, then the visual graphical progress bar graphically represents the described progress. there also should be a completion tab that can be turned on to represent the completion of the project.  There should the facility to upload photos, video, documentation associated with the relevant job. This data is kept organised with each job, ready to be distributed in an orderly manner. This database will provide the facility to collate data(like.. List of All jobs(name, address, phone number, summarised description, when issued, start job and completion dates), specific month jobs,  from its database in PDF format, and offer print out
